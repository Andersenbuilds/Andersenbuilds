    Using this overlay

    • 01

      Hook pass — draft → 10x → true 10x. Only the true line is exported. Export stays locked until the truth box is ticked.

    • 02

      Export — Download PNG gives a 1080×1920 file. Everything outside the band is transparent.

    • 03

      CapCut — Overlay → add the PNG on top of the talking-head, from 0:00 to about 0:04. No fade-in. It must be there on frame 1.

    • 04

      Log it — note "overlay hook: yes" in the Sheet row so the 3-second hold can be compared later (test plan in the research doc).

    Built to `AB_CARD_BASELINE.md` by the same tokens as the other overlays: ink band at 92% with an orange top rule (the burn-in band spec, same as the growth counter), Inter only, near-square corners, no gradient/shadow/glow. Orange is spent once, on the hook keyword, so the eye lands there. Static on purpose: the hook has to be readable on frame 1, so there is no entrance animation to wait for.
