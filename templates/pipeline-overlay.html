Pipeline Overlay

A receipt, not a stepper — no icons, no status dots, no connecting progress line. Each step is a line of type; state lives in color and a status word, the same device the stat cards already use for numbers. A hairline settles under a line once it's done, like a line printing onto a receipt.

Using this overlay

  • 01

    Relabel — edit the four `.row-label` / `.row-sub` pairs for whatever tool chain this video covers.

  • 02

    Record — OBS capture at 1080×1920, cropped to the frame. One loop ≈ 5s.

  • 03

    Layer — trim to one cycle in CapCut, mute its audio, drop over the matching screen recording.

Built against `AB_CARD_BASELINE.md` in andersenbuilds-brand — but this composition has no direct precedent there (no flow diagram has shipped yet). Deliberately avoids the icon/badge/connector-line stepper pattern, which is a generic default independent of any brand, in favor of a typographic list that matches how the stat and bar cards already carry state: color and words, not icons.
